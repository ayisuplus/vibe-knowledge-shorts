## 事实依据（逐条对应调研档案）

| 屏幕上的说法 | 档案位置 |
|---|---|
| 5000 万像素默认输出 1250 万；4080×3072 = 12,533,760 | 4.0；核实表 |
| 4 合 1 是为了暗光更干净；有全像素模式 | 4.0；核实表 |
| 每格只量一种颜色，另外两个是算出来的 | 2.3；核实表 |
| 绿占一半，因为人眼对亮度细节最敏感的波段靠近绿色 | 2.3；核实表 |
| 人眼只有三种感色细胞 | 2.1；核实表 |
| 黄光和红光 + 绿光，三个数一样就分不出来（同色异谱） | 2.1 |
| 屏幕上没有黄色的点 | 2.1 |
| 0–255，256³ = 16,777,216 | 2.2；自算 |
| 12,533,760 × 3 ≈ 3760 万 | 自算 |
| 亮度 = 加（简化）；超过 255 截断 | 2.4 |
| 对比度绕 128 拉伸（简化） | 2.5 |
| 亮度 / 对比度 / 阴影都是曲线 | 2.6 |
| 黑白不是取平均；绿 0.587 / 红 0.299 / 蓝 0.114（Rec.601） | 2.8；核实表 |
| 自然饱和度会保护已经很鲜艳的颜色和肤色 | 2.8 |
| 灯光偏黄；大脑会自动扣掉（色彩恒常性） | 2.9 |
| 白平衡 = 三个数各乘一个系数 | 2.9；核实表 |
| 滤镜 = 换色表（LUT） | 2.10 |

**故意不说的**：K 值（避免"色温越高越蓝"和滑块方向打架）；具体手机品牌；"假的""骗局"；伽马和色彩空间。
