# 第十四期 · 动画脚本（90 秒版）

> 片名：《"打工人"去哪了？》
> 规格：1920×1080 / 30fps / **90.0 秒** / 无旁白 / 字幕烧入 / 单一横屏
> 版本：v3（替代 158 秒版与废弃的 270 秒旁白版）
> 时间轴：**全部按 90 秒轴直接写死**，废弃 `remap` 新旧映射。`beats.js` 的 `SEC` 是唯一真相。

---

## 一、为什么要重写

158 秒版的问题不是"慢"，是**六段共用一套装置**：一张纸掉下来 → 表格行淡入上浮 → 盖章 → 纸被推走。六遍。观众看到的是"同一个画面转得更快"，不是"更丰富"。

90 秒版的目标不是"压时长"，是**换语法**：
- **装置轮换**：纸（静）→ 扫描/擦除（动）→ 裁决/划改（破）→ 黑场问句（空）。同一段落里不再只有"淡入"一种运动。
- **运动密度**：每个 2 秒窗口内至少有 2 个元素在动，且速度不齐（快慢错峰），不再"每 3 秒一件事"的均匀节拍。
- **镜头**：全片 6 次推拉，段落之间靠"纸被推走/推入 + 轻微推镜"过渡，不再硬切。

## 三、底层运动层（全片常驻，t 纯函数）

四条"生命感"，不占独立时间，不需要关键帧：

| 层 | 做法 | 参数 | 作用 |
|---|---|---|---|
| L1 纸纹漂移 | `.grain` 背景位移 | `translate(${6*Math.sin(t*0.31)}px, ${4*Math.cos(t*0.23)}px)` | 画面永不绝对静止 |
| L2 投影呼吸 | 纸的 `box-shadow` 模糊半径 | `28 + 3*Math.sin(t*0.9 + seed)` | 纸"浮"在桌面上 |
| L3 桌面光斑 | 背景径向渐变中心 | 缓慢横移 ±40px / 12 秒周期 | 米底不死板 |
| L4 可见颗粒 | 叠一层 8% 噪点，固定种子 | `opacity: 0.06–0.09` | 质感，同时压住色带 |

**禁止**：用累积量（`t += dt`）、用 CSS `animation`（与逐帧渲染不同步）、用黑场淡入淡出（本片只有 S6 一次，且是"收"不是"过场"）。

## 八、验收标准（渲完先看这 6 条）

1. **任一 2 秒窗口内 ≥2 个元素在动**，且速度不同（用 1fps 抽帧看相邻帧差异，均值应 >3.5）。
2. **静止秒 <15%**（158 秒版约 21%），唯一的静止是 82.15–83.05 那 0.9 秒黑场。
3. 六段**装置不重复**：纸/扫描/汇流/划改/黑场，任意相邻两段的首帧构图不能相似。
4. 6 次镜头推拉都在段内中后段，不许在段首推。
5. 字幕 32 条，最后 12 秒无字幕，金句与问句都能读完（问句两行各留 ≥1.0 秒静态）。
6. `npx hyperframes lint` 0 error / 0 warning。
