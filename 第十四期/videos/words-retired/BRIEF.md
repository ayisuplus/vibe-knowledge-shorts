## 为什么从 158 秒改成 90 秒
158 秒版六段共用同一套装置（一张纸落下 → 表格行淡入 → 盖章 → 推走），"慢"只是表象，真正的毛病是**六遍同一个动作**。90 秒版的做法不是整体快进，而是：**换掉一半段落的装置 + 加转场 + 提高段内事件密度**。逐条设计见 `03-分镜脚本/动画脚本-90s.md`。

## 技术约定
- **时间轴只有一份真相**：`beats.js` 的 `SEC` + `DUR = 90`。段内时间点全部是 90 秒轴上的**绝对秒**。
- 158 秒版用过的 `OLD` 表 + `remap(t,key)` **已废弃**（那套是"把新时间轴等比映回旧轴"的过渡方案，读起来动作一律偏快且均匀）。现在直接在 90 秒轴上重排。
- 一条驱动 tween（`film.js`，0→90），每帧调各段 `state(t)`；画面状态全由 `t` 纯函数算出，无累积量，可任意跳帧。
- `rig.js` 原语：`sheet()`、`seal()`（slap 用 easeOutBack）、`wipe(node,k,dir)`（clip-path 收放）、`dash(node,k)`（SVG 线生长）、`odo(from,to,k)`（数字滚动）、`cam(k)`（整组推拉）、`particles()`（固定种子颗粒）、`strike()`（划叉）、`scanner()`（扫描带）、`glyphs()`（逐字落）。
- **同一个动作全片只许出现两次**——这是 90 秒版不单调的硬约束。
- `sections.js` 顶部有 `cue(nodes, times, t)`（按时间表批量淡入）与 `sweep(node, k)`（底色扫过），段内优先用它们。
- 纸类：`paper`（`/redhead/.docno/.hrline/.corner/.ptitle(top)/.pbody(top)/.psign`，**ptitle/pbody 必须内联 top**）、`dossier`、`rev`、`maxim`；全屏深色 `endcard`。
- 字体：`@font-face` 里只有三个名字——**`NotoSC`**（黑）、**`NotoSerifSC`**（宋）、**`WenKai`**（霞鹜文楷）。写别的名字 lint 会报 `font_family_without_font_face`。
- 字幕：`.cap` 只做定位容器，`.capbox` 是那张纸条（内联块 + 米色半透明底 + 细边 + 投影），保证在任何底色上都读得清；`.capbox .hi` 为红。
- **`npx hyperframes lint` = 0 error / 0 warning（2026-10-24 已过）。**

## 必须守住的表述边界（来自 01-调研/调研档案.md）
- 不说"形式主义没人批评了"：官方场域至今高频（2025–2026 仍在整治）；只说**民间日常话语**退场。官方/民间场域断裂是观察点。
- 不说"打工人消失了"：只说作为**网络热词**退场，牛马接棒。
- 异化（事的/人的）是**分析视角、类比**，不是科学证明。
- 词频趋势若发布前没实测微信/百度指数，只用媒体定性（南方周末等），不杜撰数值。
- 中性文化观察，不映射评论政策；批评 AI 味对事不对产品。
