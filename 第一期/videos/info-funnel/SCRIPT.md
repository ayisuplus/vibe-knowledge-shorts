# 信息茧房 · 分镜脚本 v3（已按此制作 v3 成片）

v1、v2 存档在 `_archive/`。v3 的改动：

1. **开头不再把漏斗和“信息茧房”绑在一起**。先讲信息茧房在社会里怎么形成（人更爱看合口味的、更爱和相近的人待在一起、圈子里相似的内容反复传），说明它在推荐算法之前就有；之后才引出漏斗，漏斗明确代表“推荐算法”
2. **循环重新设计**：画面里出现一条看得见的环形轨道，上面有 4 个站（你的反应 → 记录 → 你的数字串 → 漏斗推荐），一颗光点沿轨道跑。第一圈慢、每站亮起说明；之后越转越快，左侧“你的推荐页”每转一圈多一张卡片，颜色越来越单一；最后轨道收紧，缠成茧
3. 漏斗各层内容保留，节奏压缩

- 时长 160.2 秒，横屏 1920×1080，配乐不变；音效另做（见文末）
- 配色：赛博朋克（霓虹青、热粉、电光黄，酸性绿 / 橙点缀，不用紫）

## 事实依据

| 脚本里的说法 | 依据 | 可信度 |
|---|---|---|
| “信息茧房”比喻出自桑斯坦 2006 年《信息乌托邦》（Infotopia） | 哈佛法学院文献库、牛津大学出版社书目；国内论文同样追溯到这本书 | 可靠 |
| 人更愿意接触与自己观点一致的信息 | 传播学“选择性接触”研究，长期大量实证 | 学界共识 |
| 人更愿意和相近的人来往（物以类聚） | 社会学“同质性”研究（McPherson 等，2001 年综述） | 学界共识 |
| 茧房现象早于推荐算法 | 桑斯坦 2006 年即提出；抖音开放日也持此说 | 可靠 |
| 召回 / 过滤 / 排序，双塔、协同过滤，预估多种行为概率，多样性打散与探索，用户主动行为影响推荐 | 2025 年 4 月抖音安全与信任中心开放日 | 抖音官方公开 |
| 粗排 / 精排 / 重排的分法 | 业界通用多阶段架构，抖音官方只说召回、过滤、排序 | 业界通用 |
| “概率 × 权重，加起来是综合分” | 媒体对开放日的概括 | 媒体概括 |
| 熵衡量多样性；反馈循环可能让多样性下降 | 学术研究常用；结论有分歧，字幕用“可能” | 方法真实，结论有争议 |

## 音效（已完成）

- MiniMax Music 3 实测不适合做音效：要求“单次冲击声”，生成的 4 秒里一直有旋律音高和多次起落，本质是一小段音乐
- 改用 ComfyUI 里的 MMAudio（文字生成音效），34 种素材、52 个卡点。清单在 `sfx/cues.py`，生成脚本 `sfx/generate.py`，修整包络和混音脚本 `sfx/mix.py`，输出 `assets/sfx.mp3`，在合成里以 0.85 音量叠在配乐上
- MMAudio 文字生成的“冲击声”会是持续轰鸣，所以每段都按类型重新做了包络（冲击 / 呼啸 / 提示音 / 原样）
