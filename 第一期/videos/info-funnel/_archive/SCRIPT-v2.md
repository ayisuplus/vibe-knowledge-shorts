# 信息茧房 · 分镜脚本 v2（已按此制作 v2 成片）

v1 存档在 `_archive/SCRIPT-v1.md`。v2 的改动：去掉“一条视频怎么进入候选池”那条线（审核、流量池、观众圈），全片只讲**推荐算法这个漏斗每一层怎么算**，以及**这个漏斗反复运转，怎么把你包进茧里**。

- 时长 160.2 秒，横屏 1920×1080，无旁白，只靠画面 + 屏幕文字
- 配乐：`audio/Aurelia - We Never Choose（改编版）.m4a`，112 BPM，一小节 ≈ 2.13 秒
- 风格：沿用赛博霓虹配色，主体是一个分层漏斗，漏斗下方是你的手机
- 主线：一个代表“你”的光点。你的每次下滑 → 变成数据 → 漏斗按这些数据给你挑下一条 → 你的反应再变成数据。循环越转，你在内容空间里的位置越往一个角落挤

## 屏幕文字规则

1. 只说画面里正在发生的事，不出现“信息论”“大数据”这类学科名或栏目名
2. 公式只在画面真的在用它计算时出现，且数字由画面上的数据算出来（比如熵值由屏幕上的柱状图实时算出）
3. 不放没有出处的统计数字（用户数、视频数、耗时）；示意性的数值标“示意”
4. 涉及平台机制的说法，必须能在“事实依据”表里找到出处；只有业界通用做法、不是抖音官方说法的，措辞不说“抖音就是这么做的”

## 漏斗结构（全片固定）

| 层 | 颜色 | 做什么 |
|---|---|---|
| 口：召回 | 青 | 从海量视频里拉出一批候选，几路并行 |
| 第 1 层：过滤 | 橙 | 拿掉看过的、点过不感兴趣的、重复的 |
| 第 2 层：粗排 | 蓝 | 用简单模型快速打分，砍掉大半 |
| 第 3 层：精排 | 金 | 预估你看完、点赞、评论、分享、关注的概率，加权成综合分 |
| 第 4 层：重排 | 紫 | 相似的拆开，混进一点新方向 |
| 出口 | — | 落进你的手机，成为下一条 |

## 事实依据

| 脚本里的说法 | 依据 | 可信度 |
|---|---|---|
| 推荐学习用户行为，分召回、过滤、排序几个环节 | 2025 年 4 月抖音安全与信任中心开放日 | 抖音官方公开 |
| 用了双塔召回、协同过滤、Wide&Deep | 同上 | 抖音官方公开 |
| 你和视频各自变成一串数字（向量），相近程度用逐位相乘再相加（点积）衡量 | 双塔模型的通用原理 | 通用原理，画面是简化示意 |
| 预估完播、点赞、评论、分享、关注等行为的概率 | 开放日：神经网络预估用户行为的概率；目标包括完播、评论、点赞、分享、长期消费 | 抖音官方公开 |
| “概率 × 权重，加起来是综合分” | 媒体对开放日内容的概括（“预测行为概率 × 行为价值权重 = 推荐优先级”），不是官方公式 | 媒体概括，画面只说“乘上权重加起来” |
| 粗排、精排、重排的分法 | 业界多阶段推荐的通用架构；抖音官方只说了召回、过滤、排序 | 业界通用，不说“抖音就是这四层” |
| 多样性打散、多兴趣召回、扶持长尾、随机推荐、“不感兴趣”不再展现、用户主动行为影响推荐 | 开放日报道 | 抖音官方公开（平台自述） |
| 用 H = −Σ p·log₂p 衡量推荐内容的多样性；推荐反馈循环会让多样性下降 | 学术研究常用信息熵衡量过滤气泡；多项模拟研究观察到熵先降；但也有研究结论相反 | 研究方法真实，结论有争议，所以字幕用“可能” |
| −log₂ p：越罕见的事件信息量越大 | 香农信息量的定义 | 数学定义 |
| “信息茧房”概念与算法的关系 | 抖音称概念早于推荐算法；网信部门 2024 年底把“同质化推送营造信息茧房”列为整治重点 | 两方说法都有，片子只展示机制，不站队 |
