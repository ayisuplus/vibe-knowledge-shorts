# 信息茧房 · 分镜脚本 v1（已按此制作 v1 成片）

- 时长 160.2 秒，横屏 1920×1080，无旁白，全片只靠画面 + 屏幕文字
- 配乐：`audio/Aurelia - We Never Choose（改编版）.m4a`，112 BPM，一小节 ≈ 2.13 秒
- 风格：沿用样片的赛博霓虹配色（近黑底 + 红 / 薄荷绿 / 蓝 / 金），3D 粒子漏斗为主体
- 主角：一颗金色光点 = 一条刚发布的视频，全片跟着它走

## 屏幕文字规则

1. 只说画面里正在发生的事，不出现栏目名、学科名（不写“信息论”“大数据”“知识大赏”），不放画面没演示的公式
2. 不放没有出处的具体数字（流量池人数、候选条数等）。数量变化靠粒子变多变少来表现
3. 涉及平台机制的句子，必须能在下面“事实依据”表里找到出处；只有第三方说法的，措辞要留余地
4. 每句话尽量一行，不超过 16 个字，在重拍上出现
