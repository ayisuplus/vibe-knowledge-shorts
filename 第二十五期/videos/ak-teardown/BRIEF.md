## 一句话

一支 AK（外形参考 AKM）被徒手拆开，平铺几大件，装回剖面慢放一次射击循环，再钻进零件之间的缝；计时器走到 60 秒，零件飞回，空拉一次拉机柄，弹匣卡入，硬切。机械主角是导气活塞＋旋转枪机。

## 技术约定

- `beats.js` 是时间真相；`film.js` 一条驱动 tween；`sections.js` 的 `machineState / propsState / shot` 与 `hud.js` 的 `hudState` 全是拍 n（和秒 t）的纯函数。
- `ak.js`：模型（单位厘米，x 指向枪口，z 指向枪右侧＝镜头一侧）＋运动学（`sOf / thetaOf / boltXOf`）＋ `machine(c, u, flightDt, opt)`。可分解的件各自成组：`mag / cover / springG / carrier / bolt`；静止件切左右两半，右半由 `peel(p)` 剥离（不用裁剪平面，GTAO 不认）。
- 图纸：每个网格挂一组 `EdgesGeometry` 线，`blueprint(b, x)` 切换实体与线，按 x 擦出（线材质用裁剪平面，线不进 AO）。
- 子弹按发编号：第 c 次循环击发第 c 发、推入第 c+1 发，循环首尾无缝。第二段清膛用 `fired: false`，整发被抽出抛出。
- 沙粒落地时刻在画面（`sections.js` 的 `sand`）与拟音（`tools/sfx.mjs`）里用同一个公式；落在弹匣口上方的直接穿过去。

## 镜头（draft2 起，用户反馈「镜头几乎不动、太单调」后重做）

- `sections.js` 的 `SHOTS`：每个动作一个机位，镜头之间在拍点硬切；镜头内一直在动（环绕、推拉、跟拍），叠一层很轻的手持感。
- 机位用球坐标（看点、距离、方位 az、仰角 el）；第四、五段是剖面，限制在右侧半球（|az| ≤ 60°）。
- 跟拍：n50–53 跟着弹头沿枪管走到导气孔；n27–30 绕着枪机转；n37–46 绕着枪机框转；n121–123 推到拉机柄。

## 环境（draft3 起，用户反馈「开场和背景太单调」后加）

- `env.js`：开场 n0–6 是第一人称的灰橙网格原型训练图（方块和墙，**没有任何靶子**），枪在画面右下，「F 检视」提示后做一次检视动作（`sections.js` 的 `viewmodel`，移动的是场景根 `root`）；n6 HUD 碎开、硬切进工作室。

## 必须守住的表述边界（来自 `../../01-调研/调研档案.md`）
