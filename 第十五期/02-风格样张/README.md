## 对比

| | A 绢本 | B 暗靛金丝 | C 蓝白二值 |
|---|---|---|---|
| 气质 | 明亮、平静，像翻开一页古籍 | 织金妆花，电影感 | 清爽，像一张教学示意图 |
| 底 | 绢纸 `#ece4d0` | 深靛 `#070b1d`–`#1b2552` | 冷白 `#e6edf5` + 淡方格 |
| 布面（经 / 纬） | 朱砂红 / 金褐 | 金 / 靛蓝 | 靛蓝 / 白 |
| 字体 | 宋体字幕 + 宋体引文 | 黑体字幕 + 宋体引文 | 黑体字幕 + 黑体引文 |
| 强项 | 贴「明亮、真实、平静」的偏好；引文像古籍 | 缩略图对比最强；符合契约「暗底高对比」；织金质感 | 「提 / 不提」一眼就是 0 / 1；最像讲解 |
| 风险 | 与第十四期同为米色纸感，系列里会重复；红金偏暖偏闷 | 金色面积要控制，否则俗艳；暗底上细线要加粗 | 偏冷偏「课件」，古籍气最弱 |

## 推荐

**D：以 B 为主，引文卡用 A 的纸页。**

1. 契约要求暗底高对比，B 对标头部原片，缩略图最抓眼；
2. 织金的质感和「织锦」题材天然对得上；
3. 引文卡是一页亮纸浮在暗底上，既有古籍气，又给全片多一个装置，不单调（第十四期的教训）；
4. 想要「明亮平静」选 A；C 不推荐。

## 样张里没定、后面还要改的

- **花样**：现在是 16×16 的菱纹。正式版从回纹 / 团花 / 云纹里挑（见提案第七节）。
- **花本的画法**：样张里是「结网 + 绳结」，有点像算盘。正式版要画成粗丝绳、绳结、垂穗，看着像结绳。
- **左上角的「样张 X」标签**是样张自带，正片这个位置留给作者水印。
- **顶中的时代标签**随段切换：明·1637 → 法国·1804 → 英国·1830 年代 → 今天。
- 样张里的字幕与注释是占位文案，正式文案在 `03-分镜脚本`。
