## 一句话
《天工开物》里织花的人**不知道自己织的是什么**——花样在另一条「带子」（花本）里；织机只管「读一行、提一批线、过一梭」。「织什么」和「怎么织」被拆开了。这个想法后来走得很远（穿孔纸带 → 卡片 → 雅卡尔 → 分析机），而今天你对 AI 说的话，**像**画师的稿（类比）。

## 技术约定（第五代范式）
- **时间轴只有一份真相**：`beats.js`（`BEAT`、`B(n)`、`SEC`、`L` 版面常量、`ERA`）。一条驱动 tween（`film.js`，0 → `DUR`）每帧把 `t` 交给各段的 `state(t)`；所有画面状态由 `t` 纯函数算出，无累积量，可任意跳帧。
- 「已织行数」`R(t)` = 行速表 `rateOf(n)`（行/拍）的积分（`lib.js` 的 `integ`），由 `world.js` 每帧算一次；S1 / S3 / S4 / S6 的布面与 S3 / S4 的花本都按它画。拟音里每行的落点用同一个函数算。
- 画布 2D（`fabric.js`：织锦批量路径、花本结网、梭、金光、齿轮、卡片 / 纸带 / 屏幕材质、金尘），DOM 负责文字、纸页、标签；4K 靠 DPR（`beginCanvas`）。整体缩放烘进 `setCam`，不用 CSS transform 套画布。
- `sections.js` 六段合一；窗口外段主动 `vis(el, 0)`，不靠 `return`。`rig.js`：`wipe / dash / odo / typed / handwrite / glyphs / seal`（`handwrite` 支持 `\n` 手动断行，避免标点落行首）。
- 字体：`@font-face` 只有三个名字——`NotoSC`（黑）、`NotoSerifSC`（宋）、`WenKai`（霞鹜文楷）。字体文件不入库（`assets/fonts/`，OFL）。
- 工具：`tools/shot.mjs`（定帧截图自检，`node tools/shot.mjs 12.3 45.6`）、`tools/beatfit.mjs`、`tools/sfx.mjs`、`tools/srt.mjs`。
- `npx hyperframes lint`：0 error / 0 warning。`npx hyperframes check`：ok（运行时 0；对比度 24/24；唯一的布局提示 `canvas_content_at_edge` 是全幅织锦，已用 `data-layout-allow-overflow` 标为有意）。
