# frame.md — 她经济 设计规范

## 概念

**一个被打包出售的纸娃娃。** 画面世界就是一张商品卡 + 一个吸塑包装 + 一排货架：她是纸做的，商品是纸做的，每件东西都用白色小纸扣扣在她身上，挂着价签。粉色由甜到腻、再到褪尽，最后换成“高级感”的米色——包装换了，扣子没换。

## 字体

- 粉色段：Noto Sans SC（可变字重，本地 `assets/fonts/NotoSansSC-VF.ttf`），标题 900，字幕 700
- 觉醒段起：Noto Serif SC（`assets/fonts/NotoSerifSC-VF.ttf`），500
- 字幕 46–52px；标签 40–56px；年龄爆炸贴 44px；片名 200px

## 纸娃娃

- Q 版：头大、圆眼带两个白色高光、明显腮红、小弧线嘴；儿童头身比约 1:2，成人约 1:3
- 同一张脸，年龄靠身高、发型、衣服、配件区分：3 岁双马尾 → 16 岁高马尾 → 24 岁齐肩 → 28 岁盘发 → 30 岁低丸子头 → 45 岁短发 + 一缕白发
- 所有纸元素：白色模切描边（SVG feMorphology dilate）+ 暖色投影 + 小纸扣（白色圆角矩形 + 虚线折痕）

## 构图

- 她始终站在画面中央偏左（x≈700–1000），右侧和左侧给商品与价签；字幕在底部 150px 安全区内，深酒红半透明底条
- 背景逐段加纹理：干净纸面 → 波点 → 更密的波点 + 包装条纹 → 吸塑高光
- 年龄爆炸贴固定在她头部右上；“问题”标签斜贴在她身上

## 禁止

- 紫色、紫红、蓝调粉
- 真实品牌 Logo
- 频道名、学科标签、装饰性公式
