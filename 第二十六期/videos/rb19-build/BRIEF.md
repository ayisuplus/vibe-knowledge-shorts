# 《从零造一台 RB19》 · 第 26 期正片工程

- **规格**：1920×1080，30fps，209.4 秒（超 180 秒的例外，理由见 `../../00-提案/提案.md` 第四节），无旁白，字幕烧进母版。
- **文字源**：字幕、注释带、画面描述唯一来源是 `../../03-分镜脚本/_gen/script.py`；`python _gen/make_docs.py`（在 03-分镜脚本 下）同时生成字幕文案、分镜脚本和本工程的 `assets/js/captions.js`。**不要手改 captions.js。**
- **画面自解释**（`AGENTS.md` 1.3.1）：标注在 `sections.js` 的 `defineLabels`（全＝名字＋作用，签＝名字，程＝过程，stamp＝印章）。`?nocap=1` 隐藏字幕做静音验收。

## 结构

| 文件 | 内容 |
|---|---|
| `beats.js` | 段落窗口；拍网格 `B(n)=n·BEAT`（112.96 BPM）；`Q()` 吸整拍、`H()` 吸半拍；`OUT`＝五盏灯熄灭＝第 12 拍（6.374 s） |
| `timeline.js` | **事件时刻表（纯数据）**：装配表 26 步、发车灯、刹车、海豚跳、赛季条。画面和拟音都读它 |
| `rb19.js` | 车模型：每个装配步骤一个 Group（`P[id]`），`installState` 飞入/贴合，`carState` 管姿态、透视、点头、DRS、动力单元外壳透明度 |
| `livery.js` | 涂装：漆面孪生网格＋世界平面裁切，`X` 从车头扫到车尾；颜色与标志在着色器里按车身坐标投影 |
| `props.js` | 发车灯架、1978 老车剪影与车底流线、平底板、碰撞块、尺寸框、动力单元能量流 |
| `flow.js` | 车底剖面示意（隧道顶线、低压区、粒子、下压力箭头）＋尾翼气流（DRS） |
| `overlay.js` | HUD：赛季条、零件计数器、片名、奖杯、方格旗、数字牌、图例、离地间隙标尺、海豚跳轨迹、问句 |
| `hud.js` | 标注引擎（投影到屏幕、安全区 y 135–840）、字幕、注释带 |
| `sections.js` | 全片 `state(t)` 与 `hud(t)`：镜头表（每个动作一个机位，段内持续运动，段间硬切）、标注表、数字牌 |
| `film.js` | 一条驱动 tween |

## 声音

- **BGM**：Aurelia 系 `bgm-270.wav`（112.96 BPM），从 2.303 s（重拍，`tools/beatfit.mjs`）起切；0–6.374 s 静音，五盏灯熄灭那一下音乐进；失速、刹车、点火让位；结尾硬切。用户 2026-11-09：这条已被抖音官方收录为 BGM，继续沿用。
- **拟音**：`tools/sfx.mjs`，193 个事件，时刻全部读 `timeline.js`。样本引用第二十三期的 OpenGameArt CC0 与 Woosh 生成样本（CC BY-NC 4.0，仅限非商用）；风声、电流声、涡轮啸叫、引擎声代码合成，点火不用真实比赛录音。
- 顺序：`node tools/bgm.mjs` → `node tools/sfx.mjs` → `node tools/duck.mjs`。
