- 场景源码：[`3d/lab.html`](3d/lab.html) ＋ [`3d/lab.js`](3d/lab.js)（`?d=a|b|c&k=main|quote`）；截图：`node 第二十期/02-风格样张/tools/gen-3d.mjs`（本地静态服务＋headless Chrome，走本机 GPU）。Three.js r181 从第八期复制到 `3d/vendor/`。
- 章节条、注释带、字幕和标签仍是 HTML 叠层，保证清晰。
- **成片里 3D 的意义在于镜头会动**：A 是机位贴着网格大地推进、绕代码面板转；B 是绕地球的轨道运镜、怀表转向镜头；C 是镜头沿黑板横移、射灯扫过。静帧只能看出质感，真正的 3D 感来自视差。往期第七、八、十八期用的就是同一套 Three.js 流水线，渲染成本可控（第八期 93.6 秒 GPU 渲染约 67 秒）。
- 所有 3D 场景状态都可以由 `t` 直接算出，符合 AGENTS.md 4.2「不许用累积量」的要求。

## 取舍（供拍板参考）

- **A**：「宇宙是代码」这个类比最直观，④ 段「`let t` 被删掉」、⑤ 段「进度条倒拖」都能在同一个编辑器里完成，装置之间转场顺。风险是满屏代码可能劝退不写代码的观众，正文要更多依靠字幕。
- **B**：最好看、最有「宇宙感」，地球和卫星天然承接 ③ 的 GPS。但代码母题要靠后加，④ 的「时间块」也需要另起一套装置。
- **C**：最适合讲推导（`ĤΨ = 0` 写在黑板上很自然），手写批注亲切。但长时间的炭黑底偏闷，静止秒风险高，需要粉笔「正在书写」的微动画撑住。
- 混搭 D 也可以：比如 B 的星空与怀表做 ②③，切到 A 的编辑器做 ①④⑤。
