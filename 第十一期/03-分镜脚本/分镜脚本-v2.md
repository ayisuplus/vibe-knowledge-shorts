## 镜头语言：用魔方本身转场

| 名字 | 怎么做 | 用在 |
|---|---|---|
| **钻进贴纸** | 镜头直冲一块贴纸，色块铺满全屏，变成下一场的底色 | 开场 → 展台 |
| **甩镜** | 0.3 秒横甩 90°，画面加横向动态模糊，落在下一个构图上，配一声「嗖」 | 段与段之间，全片约 6 次 |
| **层转擦除** | 镜头贴着魔方，一层转过去，黑色的机身扫过整个画面，扫完就是下一场 | 出身 → 数量 |
| **穿缝** | 一层转开一道缝，镜头从缝里钻进去，看见里面发光的十字轴 | 结构段 |
| **炸开穿镜** | 小块炸开、擦着镜头飞过去，飞完就是下一场 | 群论 → 守恒量 |
| **变速** | 慢放 → 猛加速 → 急停，配合计数器 | 「R U 重复 105 次」 |
| **环绕甩 + 希区柯克变焦** | 180° 快速环绕，落定时推镜头同时拉焦距，背景猛地拉开 | 上帝之数 20 揭晓 |
| **满屏贴纸翻牌** | 一个面铺满全屏，9 块贴纸像翻牌一样翻过去，背面就是下一个画面 | 数量 → 公式 |

## 逐段（时间先按约 130 秒排，配乐定了再卡拍）

### S1 结构（8–18）

- **穿缝**：顶层转开 30°，镜头从缝里钻进去，看见发光的十字轴，然后 26 块向四周炸开（爆炸图 + 标签）
- 字：「26 个小块：6 个中心块、12 个棱块、8 个角块」
- 字：「中心块拧在轴上，永远不动，它们就是坐标系」（数学视角：参照系）
- **甩镜** → S2

### S2 出身（18–26，压短）

- 魔中魔 + 全息 1974
- 字：「1974 年，一位建筑系老师为了讲『立体怎么动』做出了它」「据说他自己花了一个多月才拼回去」
- **层转擦除** → S3

### S3 数量：从公式里算出来（26–44）

- **满屏贴纸翻牌**：9 块贴纸翻过去，背面亮出公式的位置
- 小块飞出来排成算式，每一项都是看得见的东西：
  - 8 个角块排成一排 →「8!」（换位置）
  - 每个角块转一下 →「3⁷」（第 8 个的朝向由前 7 个决定）
  - 12 个棱块排成一排 →「12!」
  - 每个棱块翻一下 →「2¹¹」
  - 最后「÷ 2」（角和棱的奇偶要一致）
- 算式合成那一串大数字：43,252,003,274,489,856,000
- 宇宙年龄那条光（保留）：「一秒看一种，要看宇宙年龄的 100 倍」
- **甩镜** → S4

### S4 群论：每一次转动都是一个「元素」（44–66）

- 字：「数学家把魔方的所有转法，叫作一个『群』」
- **逆元（穿袜子穿鞋）**：拧 R 再拧 U；想退回去，得先撤 U、再撤 R。画面：动作条倒着播放，魔方倒着转回去。字：「先穿袜子再穿鞋，脱的时候顺序反过来」
- **阶**：「R U」这两下一直重复，**变速**：慢 → 快到模糊 → 急停。计数器 1 → 105，魔方回到复原。字：「重复 105 次，它自己回到原样」
- 再来一个：「R U2 D' B D'」，计数器飞到 **1260**。字：「这是一串动作能绕的最大圈：1260 次」
- **炸开穿镜** → S5

### S5 守恒量：为什么 12 次里只有 1 次（66–78）

- 三块仪表一起亮（动态小图示，不密）：
  - 角块的扭转加起来，永远是 3 的倍数 → 1/3
  - 翻过来的棱块，永远是偶数个 → 1/2
  - 角和棱的换位，奇偶永远一致 → 1/2
- 三个数相乘，汇成「1/12」：「随便拆了装回去，只有 1/12 的机会还拼得回去」
- 拔一个角块转 120° 塞回去（原有镜头），仪表变红：「这样的魔方，怎么拧都拼不回去」

### S6 交换子：高手的公式是怎么来的（78–88）

- 字：「A，B，再撤 A，再撤 B」
- 画面：拧一遍「R' F R' B2 R F' R' B2 R2」，**只有 3 个角块**换了位置，其余全部原样（其余小块变暗，三个角块亮青色轨迹）
- 字：「整颗魔方几乎不动，只有 3 块换了位置：速拧公式，就是这么搭出来的」
- **环绕甩** → S7

### S7 上帝之数（88–106）

- 超级翻转 20 步 + 计数器（保留），揭晓「20」时用**希区柯克变焦**
- 字：「只有全知的人，才每次都能找到最短的那条路」「按这条路走，任何一个魔方都不超过 20 步」「这个 20，被叫作『上帝之数』」
- 电脑怎么证明的（新加，三个大数字依次砸下来、一个比一个短）：
  - 「先把 4325 京种情况分成 22 亿组」
  - 「再用对称性，压到 5588 万组」
  - 「每组算 20 秒，一共约 35 个 CPU 年」（2010 年，Google 捐的计算时间）
- **甩镜** → S8

## 新加的事实（详细见调研档案）

| # | 说法 | 依据 |
