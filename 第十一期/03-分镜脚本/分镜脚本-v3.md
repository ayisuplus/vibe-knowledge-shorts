## 逐段

### S1 结构（蓝图工程室）
魔方从绿色里拉出来 → 顶层转开一道缝，镜头钻进去看见十字轴 → 26 块炸开 → 三个标签**一个一个**出来，每个停 1 秒多 → 只剩中心块和 x/y/z 三根轴 → 合拢 → 甩镜。

### S2 出身（1974 年的绘图室）
魔中魔慢慢拧出来 + 全息「1974 · 匈牙利布达佩斯」→ 层转擦除。画面加暖色胶片颗粒。

### S3 数量（深空）
每一项停 2.5 秒：
1. 8 个角块飞出来排成一排、洗牌 → **8!**
2. 角块一个个拧 → **× 3⁷**
3. 12 个棱块排成一排、洗牌 → **12!**
4. 棱块一个个翻 → **× 2¹¹**
5. **÷ 2**
6. 合拢，大数字一组一组亮起：**43,252,003,274,489,856,000 种**，停 3 秒
7. 宇宙年龄那条光拉过去：**≈ 宇宙年龄的 100 倍**

### S4 守恒量（金库）
「拆开、随手装回去，还能拼好吗？」三次演示，每次都是：拔出来 → 动一下 → 塞回去 → 金库的灯变红「拼不回去」→ 结论数字停住
1. 拧歪一个角块 → **1/3**
2. 翻转一个棱块 → **1/2**
3. 对调两个棱块 → **1/2**
4. 三个数相乘：**1/3 × 1/2 × 1/2 = 1/12**：随手装回去，12 次里只有 1 次拼得好

### S5 重复（无限光环隧道）
1. 只拧两下：**R**、**U**（慢，动作条一个个亮）
2. 一直重复：慢 → 越来越快 → 急停，隧道的光环跟着越流越快，计数器 1 → 105
3. 第 105 次：魔方自己回到原样。大字 **105 · 回到原样**，停 3 秒

### S6 群论应用（粒子实验室）
魔方化成晶格：「研究这些转法的数学，叫群论」→ 晶格外面绕起三道轨道环：「晶体的 230 种结构、基本粒子的标准模型，靠的都是它」

### S7 上帝之数（天光大厅）
1. 魔方被飞快地打乱成「超级翻转」：12 个棱块全翻过来，**最难拼的状态之一**
2. 一步一步拼回去，计数器 1、2、3……配乐抽空的那几秒停在 19，希区柯克变焦
3. 配乐回来那一下，第 20 步拧完，魔方复原，**20** 砸下来
4. 「不管打得多乱，最多 20 步，就能拼回去」→「这个 20，叫作上帝之数」→「最短的路一直都在，只是很难找：2010 年，电脑算了 35 个 CPU 年才证明它」

## 事实核对
- 上帝之数：任意状态的最优解都 ≤ 20 步（Rokicki、Kociemba、Davidson、Dethridge，2010，约 35 个 CPU 年）；超级翻转正好需要 20 步（Reid，1995）
- 1/12：角块总扭转 ≡ 0 (mod 3)、翻转的棱块数为偶数、角和棱的换位奇偶一致：1/3 × 1/2 × 1/2
- 单独对调两个棱块（角块不动）会让换位奇偶不一致，所以拼不回去
- 「R U」的阶是 105（模拟器）
