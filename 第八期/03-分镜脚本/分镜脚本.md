- **不配旁白**。字幕单独出 `.srt`（另出一版烧录预览用来审片），干净版的字幕区留空。画面里的数字、标签、大字属于画面，烧在视频里

## 视觉规范（提案，等样张确认）

**基调**：暖白纸张底加淡淡的胶片颗粒，照片是真实质感的生活照。整体像翻一本旧相册，不压抑、不暗。

| 用途 | 颜色 |
|---|---|
| 底色 | 暖白纸 #F4EEE4，极淡的纸纹，四周微微提亮（不压暗角） |
| 日历格线、空白格 | 米灰 #DDD3C4，空白格填 #EDE5D8 |
| 文字 | 深棕 #2A2420 |
| 强调（数字、关键词） | 琥珀 #C26F30（纸上对比度达标，见 ep7 经验） |
| 「第一次」的高亮（亮起的格子、发光边） | 暖粉 #E8707A，浅 #F4B3B3。**不偏洋红、不用紫** |
| 成年日常照片 | 统一调成偏冷、偏平的灰调，和童年照片的暖色拉开 |

**字体**：中文思源宋体（大标题）加思源黑体粗（标签、数字）。按 HyperFrames 的已知坑，@font-face 不许命名成 "Serif" / "Sans"。

**技术方案（提案）**：Three.js 3D 照片墙。照片卡片是带纸边的平面，有柔和的景深和真实阴影，镜头在墙前推拉。可以复用第七期的 studio 灯光、bloom、`track` 关键帧和 GPU 渲染流程。卡片「坍缩、叠起、亮起」都是 3D 位移，比 2D 更有空间感。
