# 新一期 · 开工说明

这是程序化生产的模板套件。每开一期，按下面顺序复制对应模板，跟着 `../AGENTS.md` 第 2 节的流水线走。

## 30 秒开工

1. 复制本 `_模板/` 整个目录，重命名为 `第 N 期/`（N 接最新期号）。
2. 删掉本说明里不需要的提示，保留各模板文件。
3. 按 P0→P6 顺序推进，三道用户闸门（提案 / 风格 / 分镜）没过不往下走。

## 模板清单与对应工序

| 模板 | 工序 | 说明 |
|---|---|---|
| `00-提案/提案模板.md` | P1 | 复制后填写，等用户拍板 |
| `01-调研/调研档案模板.md` | P2 | F-1…F-n 每条带链接，列「禁说」 |
| `02-风格样张/` | P3 | 出 A/B/C 定帧（PNG 1920×1080），等用户拍板 |
| `03-分镜脚本/分镜脚本模板.md` | P4 | 逐拍表＋字幕稿＋声音点位，等用户确认 |
| `videos/slug/BRIEF模板.md` | P5 | 工程合同，移到 `videos/<slug>/BRIEF.md` |
| `videos/slug/index.html` | P5 | 工程容器骨架 |
| `videos/slug/assets/js/beats.js` | P5 | 时间真相骨架，按本期拍点改 |
| `videos/slug/tools/sfx.mjs` | P5 | 本期拟音脚本骨架（只写放什么，引擎共享） |
| `06-交付/发布文案模板.md` | P6 | 标题/正文/标签/置顶/合规自检 |

## 工程骨架（videos/slug/）

模板只给了 `index.html`、`beats.js` 和薄 `sfx.mjs`。其余 js（`film/world/rig/sections/lib/captions`）从最近一期（第五代范式）复制后按本期改，结构契约见 `../AGENTS.md` 第 4 节。

**工具不再每期复制**：截图、字幕、卡点、封面、拟音引擎都在根 [`tools/`](../tools/)，用 `--project` 指向本期工程即可，命令见 `../AGENTS.md` 第 6 节。各期历史 `tools/` 副本是冻结的，不要回改。

## 不入库提醒

字体、`.wav`、渲染产物、>100MB 文件不进 git；`bgm.m4a`、`sfx.m4a` 入库。详见根 `.gitignore`。
